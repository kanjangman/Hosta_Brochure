# 농원 사진 넣는 곳 (farm photos)

이 폴더에 품종별 농원 실사 사진을 넣으면 도감 카드·출력 카드에 자동 반영됩니다.

## 파일 이름 규칙
- 파일명을 **품종 영문 id + 확장자**로 저장하세요. 예: `june.jpg`, `blue-angel.jpg`
- 형식: **JPG 또는 PNG**
- 히어로가 세로형이라 **세로 비율(3:4 권장)** 사진이 가장 예쁩니다.
